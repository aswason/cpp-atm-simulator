# cpp-atm-simulator
This is a c++ program which is like a ATM machine.When after compiling the code it should display menu and ask the user to enter their choices.
Each action are handled by functions like checkBalance , deposit and withdraw which uses the pass by reference.
The program keeps running until the user chooses to quit.
In order to compile and run it in GitHub Codespaces
First you open the GitHub repository and name your file atm_simulator.cpp
After that you launch Codepaces and select the file 
Next in the terminal you compile the program and run the program
